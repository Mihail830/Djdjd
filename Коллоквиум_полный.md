# Коллоквиум по Python: полный конспект

## Занятие 2. Запуск, устройство файла, объекты, ветвление и циклы

### 1. Python как компилируемый и интерпретируемый язык

Python — интерпретируемый язык с этапом компиляции: исходный код сначала автоматически компилируется в байт-код (файлы `.pyc` в папке `__pycache__`), а байт-код исполняется виртуальной машиной (в CPython — интерпретатором). Поэтому он «и то, и другое»: отдельного шага ручной компиляции в машинный код нет, но компиляция в промежуточное представление есть.

```python
import dis

def add(a, b):
    return a + b

dis.dis(add)   # покажет инструкции байт-кода: LOAD_FAST, BINARY_OP, RETURN_VALUE
```

### 2. Физические и логические строки

Физическая строка — то, что заканчивается переводом строки в файле. Логическая строка — одна инструкция. Одна логическая строка на нескольких физических записывается через обратный слэш в конце строки или внутри скобок `(...)`, `[...]`, `{...}` (скобки — предпочтительный способ):

```python
total = 1 + 2 + \
        3 + 4                # продолжение через обратный слэш

total = (1 + 2 +
         3 + 4)              # продолжение внутри скобок (лучше)

names = [
    'Аня',
    'Борис',
    'Вера',
]
```

Несколько логических строк на одной физической разделяются точкой с запятой (стилистически не поощряется):

```python
a = 1; b = 2
```

### 3. Выражения и инструкции

Выражение (expression) — конструкция, которая вычисляется в значение: `2 + 3`, `x > 5`, вызов функции. Инструкция (statement) — законченное действие: присваивание, `if`, `while`, `pass`. Простые инструкции занимают одну логическую строку; составные (`if`, `for`, `def`, `class`) состоят из заголовка с двоеточием и тела — блока с одинаковым отступом (PEP 8 — 4 пробела). Отступы в Python — часть синтаксиса, а не украшение.

```python
x = 2 + 3            # инструкция присваивания; справа — выражение
if x > 4:            # заголовок составной инструкции
    print('много')   # тело — блок с отступом
    print('ещё')
```

Неверный отступ приводит к `IndentationError`.

### 4. Токены

Лексемы исходного кода: **идентификаторы** (имена), **ключевые слова** (`if`, `while`, `lambda`… — их нельзя использовать как имена), **литералы** (`42`, `'hello'`, `3.14`, `True`), **операторы** (`+`, `==`, `=`), **разделители** (`( ) , : .` и т.д.).

Правила имён: только буквы, цифры и `_`, не начинается с цифры, регистр важен (`Sum` и `sum` — разные). Соглашения: `snake_case` для переменных и функций, `PascalCase` для классов, `_name` / `__name` — служебные, имена вида `__name__` — «магические», свои имена в таком виде не придумывают. Идентификатор не должен совпадать с ключевым словом.

```python
import keyword
print(keyword.kwlist)      # список всех ключевых слов

user_age = 20              # snake_case
class UserProfile: ...     # PascalCase
# 2name = 1                # SyntaxError: начинается с цифры
# class = 5                # SyntaxError: ключевое слово
```

### 5. Характеристики объекта, `==` и `is`

У каждого объекта три характеристики: **идентичность** (адрес, `id()`), **тип** (`type()`, неизменяем) и **значение**. Полезны также `isinstance()`, `dir()`, `len()`, `repr()`.

Оператор `==` сравнивает значения (вызывает `__eq__`), `is` сравнивает идентичность — «это один и тот же объект в памяти». Для чисел и строк использовать `is` нельзя: интерпретатор кэширует лишь малые целые (−5…256) и часть коротких строк.

```python
a = [1, 2]
b = [1, 2]
print(a == b)    # True  — значения равны
print(a is b)    # False — это два разных объекта

x = int('257'); y = int('257')
print(x is y)    # False (257 вне кэша малых целых)
x = int('5');   y = int('5')
print(x is y)    # True (малые целые кэшируются), но полагаться на это нельзя
```

**`isinstance(obj, type)`** — проверяет, принадлежит ли объект данному типу (или одному из указанных), возвращает `bool`. Отличие от `type(obj) is int`: `isinstance` учитывает наследование, поэтому для `bool` скажет `True`. Для простой проверки типов обычно используют именно её.

```python
isinstance(5, int)             # True
isinstance(True, int)          # True (bool — подкласс int)
isinstance(5, (int, float))    # True — подходит любой из типов
type(True) is int              # False
```

**`dir(obj)`** — возвращает список всех имён (атрибутов и методов), доступных у объекта. Это способ подсмотреть «начинку»: `dir("abc")` покажет и методы строк (`upper`, `split`…), и служебные атрибуты вида `__add__`. Без аргумента выдаёт имена в текущей области видимости — удобно для исследования в интерактивном режиме.

```python
'upper' in dir('abc')    # True
```

**`len(obj)`** — возвращает длину: количество элементов в коллекции. Работает со списками, строками, кортежами, словарями, множествами — с любыми объектами, у которых определён «магический» метод `__len__`. Для числа вызывать нельзя — будет `TypeError`:

```python
len('привет')        # 6
len([1, 2, 3])       # 3
len({'a': 1})        # 1
len(42)              # TypeError: object of type 'int' has no len()
```

**`repr(obj)`** — возвращает строку — «отладочное» представление объекта. По этой строке должно быть понятно, что за объект, а по возможности — как его воссоздать:

```python
repr('hi')      # "'hi'"  — с кавычками
repr([1, 'a'])  # "[1, 'a']"
str('hi')       # 'hi'    — без кавычек
```

Разница с `str()`: `str()` даёт человекочитаемое представление, `repr()` — «программистское», однозначное. В интерактивной оболочке при вводе выражения Python показывает именно `repr()` — поэтому строка выводится в кавычках.

Короткая мнемоника: `isinstance` — «что это?», `dir` — «что умеет?», `len` — «сколько?», `repr` — «как это выглядит для разработчика?», `str` — вывод для пользователя.

### 6. Изменяемые и неизменяемые типы

Неизменяемый объект нельзя изменить после создания — можно лишь привязать имя к новому объекту: `int`, `float`, `bool`, `str`, `tuple`, `frozenset`, `bytes`. Изменяемый можно менять «на месте»: `list`, `dict`, `set`, `bytearray`.

Практические следствия: неизменяемые можно использовать как ключи словаря и элементы множества; изменяемый объект, перед анный в функцию, может быть изменён внутри неё, и вызывающий код увидит изменения. Нюанс: неизменяемость «покрывает» только верхний уровень — кортеж может содержать список, и содержимое списка менять можно.

```python
def add_item(lst):
    lst.append(99)        # меняет исходный список

nums = [1, 2]
add_item(nums)
print(nums)               # [1, 2, 99]

s = 'abc'
# s[0] = 'X'              # TypeError: строки неизменяемы
s = 'X' + s[1:]           # создан новый объект, имя s перепривязано
```

### 7. Присваивание

`name = value` не копирует значение: имя привязывается (bind) к объекту, на который ссылается значение. Переприсваивание (`name = other`) меняет, на какой объект указывает имя, а не сам объект. Поэтому:

```python
a = [1, 2, 3]
b = a            # b — второе имя того же списка
b.append(4)
print(a)         # [1, 2, 3, 4] — изменился «общий» объект

b = [0]          # теперь b указывает на другой объект
print(a)         # [1, 2, 3, 4] — a не затронут
```

### 8. Ветвление if / elif / else

Условия проверяются сверху вниз, выполняется первый истинный блок, остальные пропускаются. `elif` и `else` необязательны. В условиях используется истинность объекта: `if items:` вместо `if len(items) > 0:`.

```python
score = 73
if score >= 90:
    grade = 'A'
elif score >= 70:
    grade = 'B'      # сработает этот блок
elif score >= 50:
    grade = 'C'      # уже не проверяется
else:
    grade = 'F'

items = []
if not items:
    print('Список пуст')
```

### 9. Цикл while

Тело повторяется, пока условие истинно. Бесконечный цикл — `while True:` с выходом по `break` (типовой шаблон меню и ввода данных). Внутри нужно гарантировать изменение переменных, влияющих на условие, иначе получится случайный бесконечный цикл.

```python
n = 5
while n > 0:
    print(n)
    n -= 1           # без этой строки цикл бесконечен

while True:          # шаблон «спрашивать, пока не введут верное»
    text = input('Число от 1 до 10: ')
    if text.isdigit() and 1 <= int(text) <= 10:
        break
    print('Неверный ввод')
```

### 10. Цикл for и range

`for` перебирает элементы итерируемого объекта:

```python
for ch in 'abc':
    print(ch)

for i in range(3):          # 0, 1, 2
    print(i)
```

`range(start, stop, step)` — ленивая последовательность целых чисел, `stop` не включается:

```python
list(range(5))          # [0, 1, 2, 3, 4]
list(range(2, 8, 2))    # [2, 4, 6]
list(range(5, 0, -1))   # [5, 4, 3, 2, 1]
```

Различия с `while`: `for` — когда известно число итераций или есть перебираемая коллекция; `while` — когда число повторений заранее неизвестно и зависит от условия. `for` не может «зависнуть» по своей логике, `while` — может.

### 11. break, continue, else в циклах

`break` немедленно выходит из текущего (внутреннего) цикла; `continue` пропускает остаток тела и переходит к следующей итерации. Блок `else` цикла выполняется, только если цикл завершился **без** `break` (типовой приём — поиск: нашли → `break`, не нашли → `else`). Во вложенных циклах `break` и `continue` действуют только на самый внутренний цикл, внешний они не прерывают.

```python
for i in range(1, 8):
    if i % 2 == 0:
        continue         # чётные пропускаем
    print(i)             # 1 3 5 7

nums = [3, 8, 11]
for x in nums:
    if x > 10:
        print('нашли', x)
        break
else:
    print('не нашли')    # выполнится, только если break не сработал

for i in range(3):
    for j in range(3):
        if j == 1:
            break        # прерывает только внутренний цикл
        print(i, j)      # (0,0) (1,0) (2,0)
```

## Занятие 3. Числовые типы

### 12. Целые числа (int)

Литералы: десятичные `42`, с разделителями разрядов `1_000_000`, в других системах: `0b1010` (двоичная), `0o17` (восьмеричная), `0xFF` (шестнадцатеричная). `int()` принимает строку (с указанием основания: `int('ff', 16)`), число (отбрасывает дробную часть: `int(3.9) == 3`), `bool`. Диапазон не ограничен — длинная арифметика, ограничение только память.

```python
1_000_000          # 1000000
0b1010             # 10
0o17               # 15
0xFF               # 255
int('ff', 16)      # 255
int('101', 2)      # 5
int(-3.9)          # -3 (отбрасывание дробной части, к нулю)
2 ** 100           # 1267650600228229401496703205376 — без переполнения
```

### 13. Числа с плавающей точкой (float)

Литералы: `3.14`, `.5`, `1e10`, `2.5e-3`. `float()` принимает число или строку (`float('1e3')`). По стандарту IEEE 754 — 64 бита (двойная точность): примерно 15–17 значащих цифр, диапазон около ±1.8·10³⁰⁸. Ограничение: большинство десятичных дробей непредставимо точно в двоичном виде.

```python
3.14, .5, 1e10, 2.5e-3     # разные формы записи
float('1e3')               # 1000.0
float(7)                   # 7.0

import sys
sys.float_info.max         # 1.7976931348623157e+308
sys.float_info.epsilon     # 2.220446049250313e-16 — машинная точность
```

### 14. +inf, −inf, nan

Специальные значения `float`: `float('inf')`, `float('-inf')` — бесконечности (например, результат переполнения), `float('nan')` — «не число», результат неопределённых операций (`inf - inf`). Особенность: `nan` не равен ничему, даже самому себе; для проверки используют `math.isnan()`. Бесконечности равны сами себе.

```python
import math
inf = float('inf')
nan = float('nan')

inf == inf          # True
inf - inf           # nan
nan == nan          # False
math.isnan(nan)     # True
1e308 * 10          # inf (переполнение)
max(5, inf)         # inf — удобная «начальная» величина при поиске минимума
```

### 15. Погрешности float

`0.1 + 0.2 != 0.3` → `True` (то есть не равны), потому что `0.1` и `0.2` в двоичном представлении — бесконечные дроби, округляемые до ближайших машинных чисел, а их сумма даёт `0.30000000000000004`. Решения: `math.isclose(a, b, abs_tol=1e-9)` — сравнение с допуском; модуль `decimal.Decimal` — точная десятичная арифметика для денег и подобных задач.

```python
import math
from decimal import Decimal

0.1 + 0.2                          # 0.30000000000000004
0.1 + 0.2 == 0.3                   # False
math.isclose(0.1 + 0.2, 0.3)       # True
math.isclose(0.0, 1e-12, abs_tol=1e-9)   # True (abs_tol нужен при сравнении с нулём)

Decimal('0.1') + Decimal('0.2') == Decimal('0.3')   # True
# Decimal создают из строки: Decimal(0.1) уже содержит погрешность float
```

### 16. bool как подтип int

`bool` — подкласс `int`: `True == 1`, `False == 0`, арифметика работает (`True + True == 2`). `True` и `False` — синглтоны, их сравнивают через `is` или напрямую. Хороший тон: возвращать/присваивать результат выражения напрямую (`return x > 0`, а не `if x > 0: return True else: return False`); не писать `if flag == True:` — достаточно `if flag:`.

```python
True + True                 # 2
sum([True, False, True])    # 2 — подсчёт истинных значений
isinstance(True, int)       # True

def is_positive(x):
    return x > 0            # правильно: сразу bool
```

### 17. Арифметические операции

`+`, `-`, `*`, `/` (истинное деление, всегда `float`), `//` (целочисленное деление — округление **вниз**, «пол»), `%` (остаток, знак как у делителя), `**` (степень). Связь: `a == (a // b) * b + a % b`. С отрицательными: `-7 // 2 == -4` (вниз, а не к нулю!), `-7 % 2 == 1`.

Приведение типов: `int` с `int` → `int` (кроме `/`), участие `float` → результат `float`, `bool` ведёт себя как `int`.

```python
7 / 2          # 3.5
8 / 2          # 4.0 (всегда float)
7 // 2         # 3
-7 // 2        # -4
7 % 2          # 1
-7 % 2         # 1
7 % -2         # -1 (знак как у делителя)
2 ** 10        # 1024
2 ** -1        # 0.5
7 // 2.0       # 3.0 (float)
```

### 18. Составное присваивание, неизменяемость чисел

`x += 1` — сокращение для `x = x + 1` (есть также `-=`, `*=`, `/=`, `//=`, `%=`, `**=`). Для изменяемых типов (`list +=`) обычно модифицируется тот же объект, для неизменяемых создаётся новый. Числа неизменяемы: любая «арифметика с переменной» на самом деле создаёт новый объект и перепривязывает имя.

```python
x = 10
print(id(x))
x += 5
print(id(x))        # другой id — создан новый объект 15

lst = [1]
print(id(lst))
lst += [2]
print(id(lst))      # тот же id — список изменён на месте
```

### 19. Сравнения и цепочки

Операторы `==`, `!=`, `<`, `>`, `<=`, `>=` возвращают `bool`. Цепочки сравнения вычисляются «по-математически»: `0 < x < 10` эквивалентно `(0 < x) and (x < 10)` — среднее выражение вычисляется один раз. Можно смешивать: `1 < 2 == True` → `False` (потому что `1 < 2 and 2 == True`, а `2 == True` — ложь).

```python
x = 5
0 < x < 10          # True
1 <= x <= 3         # False
1 < 2 < 3 < 4       # True
1 < 2 == True       # False
a = b = 7
a == b != 0         # True
```

### 20. not, and, or, ленивое вычисление

`not` — инверсия; `and` / `or` вычисляются лениво (short-circuit): `and` останавливается на первом ложном операнде, `or` — на первом истинном. Результат — не обязательно `bool`, а значение одного из операндов. Приём: `x = value or default`. Ленивость гарантирует, что правая часть не вычислится, если не нужна.

```python
0 or 'default'          # 'default'
'' or 'x' or 'y'        # 'x'
5 and 10                # 10
0 and 10                # 0
not []                  # True

x = 0
x != 0 and 10 / x > 1   # False — деления на ноль не будет

name = input('Имя: ') or 'Аноним'
```

### 21. abs() и round(), банковское округление

`abs(x)` — модуль числа. `round(x)` округляет по правилу «банковского округления» (round half to even): половины округляются к чётному — `round(2.5) == 2`, `round(3.5) == 4`, а не «всегда вверх», как интуитивно ждут. `round(x, n)` — до `n` знаков; результат `float` может всё равно содержать погрешность представления.

```python
abs(-7), abs(3.5)       # (7, 3.5)
round(0.5)              # 0
round(1.5)              # 2
round(2.5)              # 2
round(3.5)              # 4
round(3.14159, 2)       # 3.14
round(1234, -2)         # 1200 (отрицательный n — округление разрядов)
round(2.675, 2)         # 2.67 (не 2.68: 2.675 хранится неточно)
```

## Занятие 4. Списки и кортежи

### 22. Список

Изменяемая упорядоченная последовательность произвольных объектов. Быстрый доступ по индексу, добавление в конец за O(1), вставка/удаление в середине — O(n). Область применения — упорядоченные наборы однородных (и не очень) данных: коллекции, очереди, результаты.

```python
mixed = [1, 'two', 3.0, [4, 5], None]   # типы могут быть разными
mixed[0] = 100                          # список изменяем
```

### 23. Создание списков

Литерал `[1, 2, 3]`, `list()` (пустой) и `list(iterable)` (например, `list('abc')` → `['a','b','c']`). Списковое включение: `[x**2 for x in range(5)]`, с условием, с вложенными циклами (порядок вложенности — как у вложенных `for`).

```python
empty = []
empty2 = list()
list('abc')                                   # ['a', 'b', 'c']
list(range(3))                                # [0, 1, 2]
[x**2 for x in range(5)]                      # [0, 1, 4, 9, 16]
[x for x in range(10) if x % 2 == 0]          # [0, 2, 4, 6, 8]
[(x, y) for x in 'ab' for y in range(2)]      # [('a',0),('a',1),('b',0),('b',1)]
```

### 24. Длина, индексация

`len(seq)` — длина. Индексация с нуля; отрицательные индексы — с конца: `seq[-1]` — последний элемент. Выход за диапазон (`seq[len(seq)]`) вызывает `IndexError` — в отличие от срезов, которые выход за границы «прощают».

```python
seq = [10, 20, 30]
len(seq)       # 3
seq[0]         # 10
seq[-1]        # 30
seq[-3]        # 10
seq[3]         # IndexError: list index out of range
```

### 25. Срезы

`seq[start:stop:step]` — от `start` включительно до `stop` не включительно, с шагом `step`. Значения по умолчанию: `start=0`, `stop=len`, `step=1`; при отрицательном шаге порядок обратный (`[::-1]` — разворот). Всегда возвращает новый объект (для списков — поверхностная копия). Выход за границы не ошибка.

```python
L = [0, 1, 2, 3, 4, 5]
L[1:4]        # [1, 2, 3]
L[:3]         # [0, 1, 2]
L[3:]         # [3, 4, 5]
L[::2]        # [0, 2, 4]
L[::-1]       # [5, 4, 3, 2, 1, 0]
L[-2:]        # [4, 5]
L[5:]         # [5]
[1, 2, 3][5:] # []
```

### 26. Изменение элементов

По индексу: `lst[0] = 100`. Через срез — замена блока (длины могут не совпадать: `lst[1:3] = [7, 8, 9]` расширит список), вставка: `lst[1:1] = ['x']`, удаление: `lst[1:3] = []` или `del lst[1:3]`.

```python
lst = [1, 2, 3, 4]
lst[0] = 100            # [100, 2, 3, 4]
lst[1:3] = [7, 8, 9]    # [100, 7, 8, 9, 4]
lst[1:1] = ['x']        # [100, 'x', 7, 8, 9, 4]
lst[1:3] = []           # [100, 8, 9, 4]
del lst[1:3]            # [100, 4]
```

### 27. Добавление: append, extend, insert

`append(x)` — один элемент в конец; `extend(iterable)` — «размазывает» итерируемое в конец (`extend('ab')` добавит `'a'` и `'b'`); `insert(i, x)` — вставка по индексу. Частая ошибка: `append([1, 2])` добавит список как один элемент.

```python
a = [1]
a.append(2)          # [1, 2]
a.append([3, 4])     # [1, 2, [3, 4]]

b = [1]
b.extend([2, 3])     # [1, 2, 3]
b.extend('ab')       # [1, 2, 3, 'a', 'b']

c = [1, 3]
c.insert(1, 2)       # [1, 2, 3]
c.insert(100, 9)     # [1, 2, 3, 9] — слишком большой индекс = в конец
```

### 28. Удаление: del, pop, remove, clear

`del lst[i]` / `del lst[a:b]` — по индексу/срезу, без возврата значения; `pop(i)` — удаляет **и возвращает** элемент (без аргумента — последний); `remove(x)` — удаляет первое вхождение значения (если нет — `ValueError`); `clear()` — очищает весь список.

Выбор: по значению → `remove`, нужен элемент → `pop`, по индексу без значения → `del`, всё → `clear`.

```python
lst = [10, 20, 30, 20, 40]
del lst[0]         # [20, 30, 20, 40]
x = lst.pop()      # x = 40, lst = [20, 30, 20]
y = lst.pop(0)     # y = 20, lst = [30, 20]
lst.remove(20)     # [30]
lst.remove(99)     # ValueError: list.remove(x): x not in list
lst.clear()        # []
```

### 29. Итерируемость и встроенные функции

Список итерируем: `for x in lst`. Работают `sum(lst)`, `max()`, `min()` (у `max`/`min` есть параметр `key`, например `max(lst, key=len)`), `sorted(lst)` — возвращает **новый** отсортированный список (в отличие от метода `sort()`, сортирующего на месте).

```python
nums = [3, 1, 2]
sum(nums), max(nums), min(nums)       # (6, 3, 1)
max(['aa', 'b', 'cccc'], key=len)     # 'cccc'
sorted(nums)                          # [1, 2, 3], nums не изменился
nums.sort()                           # nums = [1, 2, 3], возвращает None
for i, x in enumerate(nums):          # индекс + элемент
    print(i, x)
```

### 30. Кортеж

Неизменяемая упорядоченная последовательность. Отличия от списка: нельзя добавлять/удалять/менять элементы; занимает меньше памяти; может быть ключом словаря и элементом множества (если элементы хешируемы); сигнализирует о том, что данные менять не предполагается (координаты, записи, возврат нескольких значений из функции).

```python
point = (3, 4)

def min_max(seq):
    return min(seq), max(seq)    # возвращается кортеж

lo, hi = min_max([5, 2, 9])      # распаковка
grid = {(0, 0): 'старт', (1, 2): 'выход'}   # кортеж как ключ
```

### 31. Создание кортежей

Литерал: `(1, 2, 3)`; скобки часто необязательны: `t = 1, 2`; одноэлементный — обязательна запятая: `(5,)`, иначе это просто число в скобках. `tuple()` — пустой или из итерируемого. «Кортежных включений» нет: `(x for x in ...)` — это генератор, а не кортеж; получить кортеж можно `tuple(x for x in ...)`.

```python
t1 = (1, 2, 3)
t2 = 1, 2              # (1, 2)
t3 = (5,)              # кортеж из одного элемента
t4 = (5)               # просто число 5
t5 = ()                # пустой кортеж
tuple('abc')           # ('a', 'b', 'c')
tuple(x*x for x in range(4))   # (0, 1, 4, 9)
```

### 32. Неизменяемость кортежа

Сам кортеж изменить нельзя (`t[0] = 5` → `TypeError`). Но его элементы — самостоятельные объекты, и изменяемый элемент внутри кортежа менять можно:

```python
t = (1, [2, 3])
# t[0] = 5            # TypeError: 'tuple' object does not support item assignment
t[1].append(4)        # допустимо
print(t)              # (1, [2, 3, 4])
# t[1] += [5]         # и изменит список, и вызовет TypeError на присваивании
```

### 33. Сравнение списков и кортежей

Лексикографический порядок: сравниваются попарно элементы слева направо, первый несовпадающий решает; при равенстве префикса короче считается меньшим. Списки сравниваются со списками, кортежи с кортежами; `[1, 2] == (1, 2)` → `False` (разные типы).

```python
[1, 2] < [1, 3]         # True
[1, 2] < [1, 2, 0]      # True (префикс короче)
(2, 0) > (1, 99)        # True (решает первый элемент)
[1, 2] == (1, 2)        # False
[1, 2] == [1, 2]        # True
[1, 2] < (1, 3)         # TypeError: списки и кортежи не упорядочиваются между собой
```

### 34. Общие операции последовательностей

Для всех последовательностей: `len()`, `in` / `not in` (принадлежность), конкатенация `+`, повторение `*` (`[0] * 5`), индексация, срезы, итерирование. Для списков `+=` — фактически `extend` (меняет тот же объект), `*=` — повторение на месте. Для кортежей `t += ...` создаёт **новый** кортеж (т.к. неизменяем).

Осторожно с повторением изменяемых элементов: `[[]] * 3` даёт список из **трёх ссылок на один** список!

```python
[1, 2] + [3]           # [1, 2, 3]
[0] * 5                # [0, 0, 0, 0, 0]
2 in [1, 2, 3]         # True

bad = [[]] * 3
bad[0].append(1)
print(bad)             # [[1], [1], [1]] — один и тот же список трижды

good = [[] for _ in range(3)]
good[0].append(1)
print(good)            # [[1], [], []]
```

### 35. Формы присваивания

Цепное: `a = b = 0` (оба имени — один объект). Распаковка: `x, y = 1, 2`; распаковка коллекций: `a, b, c = [1, 2, 3]`; со звёздочкой: `first, *rest = [1, 2, 3, 4]` → `rest == [2, 3, 4]`. Обмен значений без временной переменной: `a, b = b, a` (справа собирается кортеж, потом распаковывается). Число слева должно совпадать с числом элементов (со звёздочкой — «не меньше»).

```python
a = b = 0
x, y = 1, 2
x, y = y, x                       # x = 2, y = 1
first, *rest = [1, 2, 3, 4]       # first = 1, rest = [2, 3, 4]
head, *mid, tail = range(5)       # 0, [1, 2, 3], 4
a, b = [1, 2, 3]                  # ValueError: too many values to unpack
```

### 36. Поверхностное и глубокое копирование

Поверхностная копия (`lst.copy()`, `list(lst)`, срез `lst[:]`) — новый контейнер, но элементы — те же ссылки: изменение вложенного списка видно в обеих копиях. Глубокая копия (`copy.deepcopy(lst)`) рекурсивно копирует всё содержимое — полностью независимая структура. Нужна, когда есть вложенные изменяемые объекты.

```python
import copy

original = [[1, 2], [3, 4]]
shallow = original.copy()
deep = copy.deepcopy(original)

original[0].append(99)
print(shallow)    # [[1, 2, 99], [3, 4]] — вложенный список общий
print(deep)       # [[1, 2], [3, 4]]     — независимая копия

shallow.append([5])
print(original)   # внешний список не затронут: [[1, 2, 99], [3, 4]]
```

### 37. sorted(): key, reverse, устойчивость

`sorted(iterable, key=..., reverse=False)` возвращает новый список. `key` — функция, применяемая к каждому элементу для сравнения; `reverse=True` — по убыванию. Сортировка устойчива (stable): равные ключи сохраняют исходный порядок. Тот же интерфейс у метода `list.sort()` (сортировка на месте).

```python
words = ['banana', 'Apple', 'cherry']
sorted(words)                       # ['Apple', 'banana', 'cherry'] ('A' < 'b')
sorted(words, key=str.lower)        # ['Apple', 'banana', 'cherry']
sorted(words, key=len, reverse=True)# ['banana', 'cherry', 'Apple']

pairs = [('a', 2), ('b', 1), ('c', 2)]
sorted(pairs, key=lambda p: p[1])   # [('b',1), ('a',2), ('c',2)] — 'a' перед 'c' (устойчивость)

nums = [3, 1, 2]
nums.sort(reverse=True)             # на месте: [3, 2, 1]
```

## Занятие 5. Строки

### 38. Строка

Неизменяемая упорядоченная последовательность символов (Unicode). Характеристики: неизменяемость (все методы возвращают новую строку), индексация и срезы, итерируемость. Области применения: текст, ключи словарей, парсинг, форматирование вывода.

```python
s = 'Привет'
s[0]          # 'П'
s[1:4]        # 'рив'
for ch in s:  # перебор символов
    print(ch)
# s[0] = 'п'  # TypeError: строки неизменяемы
```

### 39. str и repr()

`str(obj)` — «человеческое» представление (вызывает `__str__`), `repr(obj)` — «отладочное», по возможности валидное Python-выражение (вызывает `__repr__`). Для строки видны кавычки: `str('a')` → `a`, `repr('a')` → `'a'`. В интерактивном режиме вывод объекта — это `repr()`.

```python
s = 'a\nb'
print(str(s))     # a   (и перенос строки)
                  # b
print(repr(s))    # 'a\nb' — виден служебный символ

from datetime import date
d = date(2026, 10, 21)
str(d)            # '2026-10-21'
repr(d)           # 'datetime.date(2026, 10, 21)'
```

### 40. Строковые литералы

`'...'`, `"..."` — эквивалентны; внутри одинарных можно не экранировать двойные и наоборот. Тройные кавычки `'''...'''` — многострочные, могут содержать переводы строк (используются и как docstring). Пустая строка — `''` (ложна). Неявная конкатенация соседних литералов: `'ab' 'cd'` → `'abcd'` (полезно для длинных строк в коде). В многострочном литерале отступы перед строками — часть строки (реальные пробелы).

```python
a = 'Say "hi"'
b = "It's fine"
c = '''Первая строка
Вторая строка'''
d = 'ab' 'cd'          # 'abcd'

long_text = ('Очень длинная строка, '
             'разбитая на части в коде')
```

### 41. Escape-последовательности

`\n` — перевод строки, `\t` — табуляция, `\'`, `\"` — кавычки, `\\` — сам обратный слэш, `\r` — возврат каретки, `\b` — забой (backspace). Если после `\` стоит неизвестная последовательность — слэш сохраняется (но так писать не стоит).

```python
print('a\tb\nc')       # a    b
                        # c
print('Путь: C:\\temp') # Путь: C:\temp
print('It\'s')          # It's
len('\n')               # 1 — это один символ
```

### 42. r-строки

Префикс `r` («сырая» строка): обратные слэши не интерпретируются, `r'\n'` — это два символа «слэш + n». Незаменимы для регулярных выражений и путей Windows.

```python
r'\n'                  # '\\n' — два символа
len(r'\n')             # 2
path = r'C:\Users\name'
import re
re.findall(r'\d+', 'a12b345')   # ['12', '345']
# r'abc\' — ошибка: сырая строка не может заканчиваться одиночным слэшем
```

### 43. f-строки

Префикс `f`: внутри `{}` подставляются выражения. Поддерживают спецификаторы формата (`:.2f`, `:>10`, `:,`), вложенные выражения и даже f-строки внутри f-строк. Вычисляются в момент выполнения.

```python
name, x = 'Аня', 3.14159
f'{name} = {x:.2f}'            # 'Аня = 3.14'
f'{2 + 3}'                     # '5'
f'{name!r}'                    # "'Аня'" — применён repr
f'{x=}'                        # 'x=3.14159' (отладочная форма, Python 3.8+)
width = 8
f'{x:{width}.3f}'              # '   3.142' — ширина из переменной
```

### 44. Строки как последовательности

Поддерживают `len()`, индексацию (`s[0]`, `s[-1]`), срезы, `in` / `not in` (поиск подстроки), `+` (конкатенация), `*` (повторение), итерирование по символам. Изменить символ по индексу нельзя — только собрать новую строку.

```python
s = 'python'
len(s)             # 6
s[-1]              # 'n'
s[::-1]            # 'nohtyp'
'th' in s          # True
s + '!'            # 'python!'
'-' * 10           # '----------'
s = s[:1].upper() + s[1:]   # 'Python' — новая строка
```

### 45. Сравнение строк

`==` / `!=` — посимвольно; `<`, `>` — лексикографически по кодовым точкам Unicode (регистр важен: `'Z' < 'a'`). Истинность: непустая строка — `True`, пустая `''` — `False`.

```python
'abc' == 'abc'      # True
'Z' < 'a'           # True (ord('Z') = 90, ord('a') = 97)
'apple' < 'apricot' # True
'10' < '9'          # True — сравниваются символы, а не числа
bool('')            # False
bool(' ')           # True — пробел это символ
ord('a'), chr(97)   # (97, 'a')
```

### 46. Способы форматирования

Три способа: f-строки (современный, предпочтительный), метод `"{}".format(x)`, оператор `%` (старый, C-стиль). Все дают схожий результат; f-строки — самые читаемые и быстрые.

```python
name, val = 'x', 42
f'{name} = {val}'               # f-строка
'{} = {}'.format(name, val)     # format
'{1} и {0}'.format('a', 'b')    # 'b и a' — по номерам
'%s = %d' % (name, val)         # старый стиль
```

### 47. Форматирование чисел

В f-строках: `f"{pi:.2f}"` — два знака после точки; `f"{x:.1%}"` — проценты (умножит на 100 и добавит `%`); `f"{n:,}"` — разделители разрядов; ширина и выравнивание: `>`, `^`, `<`; нули слева: `f"{n:05d}"`. Округление при форматировании — по тому же правилу, что и `round()`.

```python
pi, x, n = 3.14159, 0.256, 1234567
f'{pi:.2f}'      # '3.14'
f'{x:.1%}'       # '25.6%'
f'{n:,}'         # '1,234,567'
f'{42:05d}'      # '00042'
f'{5:>10}|'      # '         5|'
f'{5:^10}|'      # '    5     |'
f'{5:<10}|'      # '5         |'
f'{255:b} {255:x} {255:o}'   # '11111111 ff 377'
f'{1e6:.2e}'     # '1.00e+06'
```

### 48. Выравнивание: ljust, rjust, center

`s.ljust(width)` — слева текст, пробелы справа; `s.rjust(width)` — наоборот; `s.center(width)` — по центру. Второй аргумент — заполняющий символ. Если строка уже длиннее `width` — возвращается без изменений. Для чисел есть ещё `zfill`.

```python
'abc'.ljust(6) + '|'        # 'abc   |'
'abc'.rjust(6) + '|'        # '   abc|'
'abc'.center(7, '*')        # '**abc**'
'7'.rjust(3, '0')           # '007'
'7'.zfill(3)                # '007'
'abcdef'.ljust(3)           # 'abcdef' — без изменений
```

### 49. Регистр

`s.lower()` — нижний регистр, `s.upper()` — верхний. Возвращают новую строку. Используются для нормализации перед сравнением. Для сравнения без учёта регистра лучше `casefold()`; есть ещё `title()`, `capitalize()`, `swapcase()`.

```python
'Python'.lower()      # 'python'
'Python'.upper()      # 'PYTHON'
answer = 'ДА'
answer.lower() == 'да'          # True
'hello world'.title()           # 'Hello World'
'hello world'.capitalize()      # 'Hello world'
```

### 50. Методы проверки

Все возвращают `bool` и требуют непустую строку: `islower()` / `isupper()` — все буквы в соответствующем регистре (и есть буквы); `isalpha()` — только буквы; `isdigit()` — только цифры; `isalnum()` — буквы и цифры; `isspace()` — только пробельные символы. Пустая строка для всех — `False`.

```python
'abc'.isalpha()      # True
'abc1'.isalpha()     # False
'123'.isdigit()      # True
'-5'.isdigit()       # False — минус не цифра
'ab12'.isalnum()     # True
'  \t'.isspace()     # True
'abc'.islower()      # True
'ABC1'.isupper()     # True
''.isalpha()         # False
```

### 51. Очистка строк

`strip()` / `lstrip()` / `rstrip()` — убирают пробельные символы с краёв (обеих / слева / справа; можно передать набор символов); `replace(old, new)` — замена всех вхождений; `removeprefix(p)` / `removesuffix(s)` — отрезают префикс/суффикс, если он есть (Python 3.9+).

```python
'  hi \n'.strip()          # 'hi'
'  hi  '.lstrip()        # 'hi  '
'  hi  '.rstrip()        # '  hi'
'xxhixx'.strip('x')      # 'hi' — набор символов, не подстрока
'a-b-c'.replace('-', '') # 'abc'
'a-b-c'.replace('-', '+', 1)   # 'a+b-c' — не более одной замены
'test_file.py'.removesuffix('.py')   # 'test_file'
'http://x'.removeprefix('http://')   # 'x'
```

### 52. split() и join()

`s.split()` — разбиение по пробелам (любому их количеству) в список; `s.split(sep)` — по разделителю; `sep.join(iterable_of_str)` — склейка. Важно: `join` принимает только строки — числа нужно предварительно преобразовать.

```python
'  a  b   c '.split()       # ['a', 'b', 'c']
'a,b,,c'.split(',')         # ['a', 'b', '', 'c']
'a b c'.split(' ', 1)       # ['a', 'b c'] — не более одного разбиения
', '.join(['a', 'b'])        # 'a, b'
'-'.join(str(i) for i in range(3))   # '0-1-2'
', '.join([1, 2])           # TypeError: нужны строки
```

### 53. Поиск в строках

`startswith(p)` / `endswith(s)` — начинается/заканчивается ли (принимают и кортеж вариантов); `find(sub)` — индекс первого вхождения или `-1`, если нет; `rfind` — поиск с конца; `index()` / `rindex()` — то же, но при отсутствии возбуждают `ValueError`. Также `count(sub)` — число непересекающихся вхождений.

```python
s = 'abracadabra'
s.startswith('abra')              # True
s.endswith(('.py', '.txt'))       # False — кортеж вариантов
s.find('bra')                    # 1
s.rfind('bra')                   # 8
s.find('xyz')                    # -1
s.index('xyz')                   # ValueError: substring not found
s.count('a')                     # 5
```

### 54. Моржовый оператор :=

Присваивание внутри выражения (PEP 572). Отличие от `=`: это выражение, у него есть значение, его можно использовать прямо в условии. Типичное применение — чтение в цикле без дублирования. Также в списковых включениях. Приоритет ниже, чем у сравнений, поэтому в условиях часто нужны скобки; нельзя использовать как обычное присваивание на верхнем уровне инструкции (`x := 5` сам по себе — ошибка, нужно `(x := 5)`).

```python
while (line := input('> ')) != 'quit':     # без дублирования input()
    print('Вы ввели:', line)

data = [1, -2, 3]
result = [y for x in data if (y := x * 2) > 0]   # [2, 6]

if (n := len(data)) > 2:
    print(f'Слишком много элементов: {n}')
```

### 55. match-case

Конструкция сопоставления с образцом (Python 3.10+), в отличие от классического `switch` других языков: выполняется **первый совпавший** образец, без «проваливания» вниз; образцы — структурные шаблоны, а не просто значения: литералы (`case 0:`), захват значения (`case x:`), кортежи/списки (`case (x, y):`), словари (`case {"name": n}:`), классы (`case Point(x=0, y=0):`), `|` — альтернативы, `case _:` — «любое значение» (аналог `default`). Заглавное имя в образце интерпретируется как константа, строчное — как захват переменной.

```python
def describe(cmd):
    match cmd:
        case 'start' | 'go':             # альтернативы
            return 'запуск'
        case ('move', x, y):             # кортеж: захват x и y
            return f'движение в {x}, {y}'
        case {'name': n}:                # словарь с ключом name
            return f'имя: {n}'
        case [first, *rest]:             # список из 1+ элементов
            return f'первый {first}, остальных {len(rest)}'
        case int(n) if n > 0:            # класс + условие (guard)
            return 'положительное число'
        case _:                          # default
            return 'неизвестно'

describe(('move', 1, 2))   # 'движение в 1, 2'
```

## Занятие 6. Словари и множества

### 56. Словарь

Изменяемая коллекция пар «ключ → значение», неупорядоченная по смыслу (с Python 3.7 сохраняет порядок вставки). Ключи уникальны и хешируемы, значения — любые. Быстрый доступ по ключу за O(1). Области применения: ассоциативные данные (записи, конфигурации), подсчёты, кэши, индексы.

```python
student = {'name': 'Аня', 'age': 19, 'grades': [5, 4, 5]}
student['name']        # 'Аня'
len(student)           # 3
```

### 57. Хеш-функции и hash()

Хеш-функция превращает объект в целое число, по которому словарь/множество быстро находят «корзину» хранения. `hash(obj)` возвращает хеш. Хешируемы (неизменяемые) объекты: числа, строки, кортежи из хешируемых, `frozenset`, `bool`. Не хешируемы: `list`, `dict`, `set` — они изменяемы, и их хеш «поплыл» бы при изменении, сломав структуру словаря. Требование: у равных объектов хеши равны (`a == b` → `hash(a) == hash(b)`).

```python
hash('abc')            # целое число (у строк меняется между запусками)
hash((1, 2))           # работает
hash(1) == hash(1.0)   # True — 1 == 1.0
hash([1, 2])           # TypeError: unhashable type: 'list'
hash((1, [2]))         # TypeError: кортеж с изменяемым элементом не хешируем
```

### 58. Ключи словаря

Ключи должны быть хешируемыми (неизменяемыми) — строки, числа, кортежи; список или множество ключом быть не могут. Повторяющиеся ключи в литерале не ошибка, но действует последний. Ключи `1` и `1.0` (и `True`) считаются одинаковыми, так как равны и имеют равный хеш.

```python
{'a': 1, 'a': 2}          # {'a': 2}
{(0, 0): 'начало'}        # кортеж — допустимый ключ
{[1, 2]: 'x'}             # TypeError: unhashable type: 'list'
{1: 'int', 1.0: 'float'}  # {1: 'float'} — ключ остался первый, значение последнее
d = {}
d[True] = 'a'; d[1] = 'b'
print(d)                  # {True: 'b'}
```

### 59. Создание словарей

Литерал: `{'a': 1}`, пустой: `{}` (не `set()`!). Словарное включение: `{k: k**2 for k in range(4)}`. Конструктор: `dict(a=1, b=2)`, `dict([('a', 1)])`, `dict(zip(keys, values))`. `dict.fromkeys(iterable, value=None)` — словарь с одинаковым значением для всех ключей (аккуратно с изменяемым значением — это один общий объект).

```python
empty = {}
{k: k**2 for k in range(4)}              # {0: 0, 1: 1, 2: 4, 3: 9}
dict(a=1, b=2)                           # {'a': 1, 'b': 2}
dict([('a', 1), ('b', 2)])               # {'a': 1, 'b': 2}
dict(zip(['x', 'y'], [10, 20]))          # {'x': 10, 'y': 20}
dict.fromkeys(['a', 'b'], 0)             # {'a': 0, 'b': 0}

bad = dict.fromkeys(['a', 'b'], [])
bad['a'].append(1)
print(bad)                               # {'a': [1], 'b': [1]} — общий список!
```

### 60. Обход словаря

Итерирование по словарю — по ключам: `for k in d:`. Методы: `keys()` (ключи), `values()` (значения), `items()` (пары-кортежи). Возвращают объекты-представления (view objects) — живые «окна» в словарь: отражают его текущее состояние, поддерживают `in`, `len()`; у `keys()` — операции множеств.

```python
d = {'a': 1, 'b': 2}
for k in d:                    # ключи
    print(k)
for v in d.values():           # значения
    print(v)
for k, v in d.items():         # пары
    print(k, v)

keys = d.keys()
d['c'] = 3
print(keys)                    # dict_keys(['a', 'b', 'c']) — представление «живое»
d.keys() & {'a', 'z'}          # {'a'} — операции множеств
```

### 61. Изменение размера при итерировании

Добавлять или удалять элементы словаря/множества прямо во время итерирования по нему нельзя — возбуждается `RuntimeError` («dictionary changed size during iteration»). Безопасные решения: итерироваться по копии (`for k in list(d):`) и внутри удалять; или собрать изменения и применить после цикла; или строить новый словарь включением. Изменять значения существующих ключей при этом можно.

```python
d = {'a': 1, 'b': 2, 'c': 3}
# for k in d:
#     if d[k] % 2: del d[k]        # RuntimeError

for k in list(d):                  # итерация по копии ключей
    if d[k] % 2:
        del d[k]
print(d)                           # {'b': 2}

d = {'a': 1, 'b': 2, 'c': 3}
d = {k: v for k, v in d.items() if v % 2 == 0}   # новый словарь
```

### 62. Чтение элементов

`d[key]` — значение или `KeyError`, если ключа нет. `d.get(key, default=None)` — значение или значение по умолчанию (без ошибки). `d.setdefault(key, default)` — если ключа нет: вставляет `default` и возвращает его; если есть — возвращает существующее значение, ничего не меняя. Типовой приём подсчёта: `d[k] = d.get(k, 0) + 1`.

```python
d = {'a': 1}
d['a']                  # 1
d['x']                  # KeyError: 'x'
d.get('x')              # None
d.get('x', 0)           # 0
d.setdefault('x', 10)   # 10, теперь d = {'a': 1, 'x': 10}
d.setdefault('a', 99)   # 1 — существующее значение не меняется

count = {}
for ch in 'abracadabra':
    count[ch] = count.get(ch, 0) + 1
print(count)            # {'a': 5, 'b': 2, 'r': 2, 'c': 1, 'd': 1}

groups = {}
groups.setdefault('fruit', []).append('apple')   # группировка
```

В исходном конспекте приём подсчёта записан как `d[k] = d.setdefault(k, 0) + 1` — он тоже работает, но `get` проще и не делает лишней вставки.

### 63. Добавление и изменение

Присваивание по ключу: `d[key] = value` — добавляет новый или перезаписывает существующий. `d.update(other)` — сливает: принимает словарь, пары или именованные аргументы; существующие ключи перезаписываются. Операторы `|` (объединение, создаёт **новый** словарь, Python 3.9+) и `|=` (обновляет на месте): `d1 | d2`, при конфликте побеждает правый операнд.

```python
d = {'a': 1}
d['b'] = 2                    # добавление
d['a'] = 100                  # перезапись
d.update({'c': 3, 'a': 0})    # {'a': 0, 'b': 2, 'c': 3}
d.update(x=9)                 # именованные аргументы
d.update([('y', 8)])          # пары

d1 = {'a': 1, 'b': 2}
d2 = {'b': 20, 'c': 30}
d1 | d2                       # {'a': 1, 'b': 20, 'c': 30} — d1 не изменён
d1 |= d2                      # d1 изменён на месте
```

### 64. Удаление

`del d[key]` — удалить ключ (нет ключа → `KeyError`); `d.pop(key, default)` — удалить и **вернуть** значение; `d.popitem()` — удалить и вернуть последнюю вставленную пару; `d.clear()` — очистить всё. Выбор: нужно значение → `pop`; просто удалить → `del`; «последний» элемент → `popitem`; всё → `clear`.

```python
d = {'a': 1, 'b': 2, 'c': 3, 'd': 4}
del d['a']              # {'b': 2, 'c': 3, 'd': 4}
v = d.pop('b')          # v = 2
d.pop('zzz', None)      # None — без ошибки благодаря default
d.pop('zzz')            # KeyError
d.popitem()             # ('d', 4) — последняя вставленная пара
d.clear()               # {}
```

### 65. in и производительность

`key in d` — проверка наличия **ключа** (значения ищут через `d.values()`). В словаре и множестве поиск — O(1) в среднем (хеш-таблица), в списке — O(n) полный перебор. Поэтому «есть ли элемент» в большой коллекции проверяют через множество, а не список.

```python
d = {'a': 1}
'a' in d                  # True
1 in d                    # False — 1 это значение, а не ключ
1 in d.values()           # True — но это перебор, O(n)

big_list = list(range(1_000_000))
big_set = set(big_list)
999_999 in big_list       # медленно: перебор
999_999 in big_set        # быстро: хеш
```

### 66. Множество

Изменяемая неупорядоченная коллекция **уникальных** хешируемых элементов; дубликаты автоматически схлопываются. Порядок не гарантирован, индексации нет. Области применения: удаление дубликатов, быстрая проверка принадлежности, операции теории множеств (пересечения, разности).

```python
{1, 2, 2, 3}                        # {1, 2, 3}
list(set([3, 1, 3, 2]))             # дубликаты убраны (порядок не гарантирован)
dict.fromkeys([3, 1, 3, 2])         # удаление дубликатов с сохранением порядка: ключи [3, 1, 2]
```

### 67. Создание множеств

Литерал: `{1, 2, 3}`. Пустое множество — только `set()` (литерал `{}` даёт словарь!). `set(iterable)` — из итерируемого. Множественное включение: `{x**2 for x in range(5)}`.

```python
s = {1, 2, 3}
empty = set()                       # не {}
type({})                            # <class 'dict'>
set('aab')                          # {'a', 'b'}
{x**2 for x in range(5)}            # {0, 1, 4, 9, 16}
{[1, 2]}                            # TypeError: элементы должны быть хешируемыми
```

### 68. Добавление и принадлежность

`s.add(x)` — один элемент; `s.update(iterable)` — добавить все элементы итерируемого (аналог `|=`, но оператор `|=` работает только с множествами, а `update` «размазывает» любой итерируемый объект). Проверка: `x in s` — очень быстро, O(1) в среднем.

```python
s = {1, 2}
s.add(3)                 # {1, 2, 3}
s.add(3)                 # без изменений — дубликатов нет
s.update([4, 5], 'ab')   # {1, 2, 3, 4, 5, 'a', 'b'}
s |= {10}                # ок
s |= [11]                # TypeError: |= только для множеств
3 in s                   # True
```

### 69. Удаление

`s.remove(x)` — удалить элемент, нет элемента → `KeyError`; `s.discard(x)` — то же, но **без** ошибки, если элемента нет; `s.pop()` — удалить и вернуть произвольный элемент (пустое множество → `KeyError`); `s.clear()` — очистить. Выбор: не уверены, есть ли элемент → `discard`; нужна ошибка как контроль → `remove`.

```python
s = {1, 2, 3, 4}
s.remove(1)        # {2, 3, 4}
s.remove(99)       # KeyError: 99
s.discard(99)      # ничего не произошло
x = s.pop()        # произвольный элемент
s.clear()          # set()
set().pop()        # KeyError: 'pop from an empty set'
```

### 70. Операции теории множеств

Объединение `a | b` / `a.union(b)`; пересечение `a & b` / `a.intersection(b)`; разность `a - b` / `a.difference(b)` (элементы `a`, которых нет в `b`); симметрическая разность `a ^ b` / `a.symmetric_difference(b)` (элементы ровно одного из множеств). Отличие форм: операторы требуют **множества с обеих сторон**, методы принимают любой итерируемый. Методные формы не меняют исходное множество; есть также «на месте»-версии: `a |= b`, `a &= b`, `a -= b`, `a ^= b`.

```python
a = {1, 2, 3}
b = {3, 4}
a | b                   # {1, 2, 3, 4}
a & b                   # {3}
a - b                   # {1, 2}
b - a                   # {4} — разность не симметрична
a ^ b                   # {1, 2, 4}

a.union([7, 8])         # {1, 2, 3, 7, 8} — методу подойдёт список
a | [7, 8]              # TypeError
a &= b                  # a = {3} — изменение на месте
```

### 71. Подмножество и надмножество

`a <= b` / `a.issubset(b)` — `a` подмножество `b` (нестрогое, возможно равно); `a < b` — строгое подмножество (`a <= b and a != b`); симметрично `a >= b` / `a.issuperset(b)` и `a > b`. Это частичный порядок: множества могут быть несравнимы (ни то, ни другое не подмножество другого), тогда `<`, `<=` дают `False` — и это не ошибка. Методные формы, как и в операциях выше, принимают любой итерируемый. Дополнительно: `a.isdisjoint(b)` — нет общих элементов.

```python
{1, 2} <= {1, 2, 3}        # True
{1, 2} < {1, 2}            # False — не строгое
{1, 2} <= {1, 2}           # True
{1, 2, 3} >= {2}           # True
{1, 2}.issubset([1, 2, 3]) # True — методу подойдёт список

a, b = {1, 2}, {2, 3}
a < b, a > b, a == b       # (False, False, False) — несравнимы
{1, 2}.isdisjoint({3, 4})  # True
set() <= {1}               # True — пустое множество подмножество любого
```

### 72. frozenset

Неизменяемая версия множества: создаётся `frozenset(iterable)`, изменять нельзя (нет `add`, `remove`, `update` и т.п.). Зато он хешируем → может быть **ключом словаря** и элементом другого множества (в том числе множества множеств). Операции чтения (`|`, `&`, `-`, `^`, сравнения, `len`, `in`) работают так же, как у `set`, и возвращают объект типа левого операнда. Применение: константные наборы, ключи, элементы множеств.

```python
f = frozenset([1, 2, 3])
# f.add(4)                          # AttributeError
hash(f)                             # работает
d = {frozenset({1, 2}): 'пара'}     # frozenset как ключ словаря
d[frozenset({2, 1})]                # 'пара' — порядок не важен

set_of_sets = {frozenset({1}), frozenset({2})}   # допустимо
# {{1}, {2}}                        # TypeError: set нехешируем

type(frozenset({1}) | {2})          # frozenset — тип левого операнда
type({2} | frozenset({1}))          # set
```
